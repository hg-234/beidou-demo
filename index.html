L0 · TRUSTED TIME-SPACE BASE

可信时空底座：可信标签 · 哈希链 · 篡改检测

每条采样记录封装为 字段定序 的可信时空标签；记录以哈希链串联，Cn = H(Cn−1 ‖ 记录)。篡改任一字段 → 链校验立即定位首个失配块。

可信时空标签可点击编辑

哈希链校验逐块比对

链完整：全部块哈希一致，未检测到篡改。
机制说明：链首 C0 公开、链尾周期性外部锚定（示意）；哈希在确定性编码（字段定序 + 数值定点化 + UTC 固定格式）后计算，保证可复现。演示用轻量哈希（FNV-1a）仅表达机制，工程实现应换 SHA-256。
工程实现要点（红队补强）：①编码带长度前缀 / 域分隔，避免拼接歧义（推荐 JCS / CBOR 规范化）；②哈希载荷含 schema 版本号；③定点化写明舍入方式与量化单位；④时间统一 RFC3339 固定精度 + 闰秒策略；⑤哈希链只保证顺序与完整性，可信时间需外部锚定 + 签名，防"事后整链重算"；⑥记录缺失须可区分（留空位 / 补块）。

L1 · SYNCHRONIZED SAMPLING

多断面同步采样：用同一可信时间基约束迁移时间窗

      L3 · EXPLAINABLE AI (ADVISORY LAYER)

      AI 辅助决策：只做"解释层"，结论由人确认

      用 SHAP 归因 给出“排序为何是这样”的解释（预计算演示值）。AI 只给“线索”、人工给“结论”：AI 不参与时间窗、不做因果与责任认定；任何结论须经人工复核留痕后方可采信。

      SHAP 归因（对首选候选的贡献解释）演示口径

      归因值表示"该特征对把此候选排到前列的贡献方向与大小"，不是污染量、不是责任比例。
